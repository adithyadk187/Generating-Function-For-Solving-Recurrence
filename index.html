Core Concepts & Theory

Fundamental mathematical principles behind Ordinary Generating Functions (OGFs)

01

Formal Power Series

A(x) = ∑n=0∞ an xn

Encodes sequence terms aₙ as coefficients of a power series. Convergence is not required; it functions purely as an algebraic container.

02

Shift Operator Property

x · A(x) = ∑n=1∞ an-1 xn

Multiplying by xk shifts index positions by k, enabling linear recurrences to convert directly into linear polynomial equations.

03

Partial Fractions

A(x) = C₁/(1 - r₁x) + C₂/(1 - r₂x)

Decomposes rational functions P(x)/Q(x) into standard geometric series sum expansions 1/(1 - rx) = ∑ (r)ⁿ xⁿ.

04

Closed-Form Extraction

an = [xn] A(x)

Reads off the exact formula for aₙ directly by matching powers of xⁿ from the decomposed geometric terms.

Worked Examples

Step-by-step mathematical solutions with 1-click interactive loading

Example 1

Fibonacci Sequence

Homogeneous 2nd Order Recurrence

an = an-1 + an-2

Initial values: a₀ = 0, a₁ = 1

Generating Function:

A(x) = x / (1 - x - x²)

Closed Form: Binet's Formula

an = (1/√5) [ ((1+√5)/2)ⁿ - ((1-√5)/2)ⁿ ]

Example 2

Geometric Non-Homogeneous

1st Order with Exponential Term

an = 3an-1 + 2n

Initial value: a₀ = 1

Generating Function:

A(x) = 1 / ((1 - 3x)(1 - 2x))

Closed Form:

an = 3n+1 - 2n+1

Example 3

Doubling + Constant

Tower of Hanoi Move Counter

an = 2an-1 + 1

Initial value: a₀ = 1

Generating Function:

A(x) = 1 / ((1 - 2x)(1 - x))

Closed Form:

an = 2n+1 - 1
